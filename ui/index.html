🔍 Breaking-Change Detective

Static analysis pipeline that diffs a changed API contract, discovers every consumer in the codebase, and produces a verdict — BREAKS / BREAKS_SILENTLY / LATENT / INVESTIGATE / UNAFFECTED — for each one via parallel LLM subagent reasoning.

Architecture: deterministic diff/consumer discovery in Python, verdict reasoning via Bob's native parallel subagent calls.

This page shows two validated runs. Live analysis runs via Bob in an IDE session.

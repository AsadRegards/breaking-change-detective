Bob was used in two distinct ways: as the development partner building the tool, and as the reasoning engine running inside it.

As a development partner, Bob scaffolded and iterated on the pipeline’s deterministic stages: a diff parser that extracts a semantic “contract delta” from a git diff—not just raw text, but changes to status codes, response shapes, and error signaling—and a consumer-discovery script that finds candidate call sites across a polyglot codebase (Python, TypeScript, and Java), filtering raw matches down to real code. Along the way, Bob also diagnosed a genuine environment bug in the target demo app: an unpinned mcp dependency silently breaking fastapi-mcp on fresh installs. We fixed and documented it as a real-world example of the same failure class this tool targets.

As the reasoning engine, Bob is the mechanism that makes the tool work, not simply a wrapper around it. Instead of routing impact analysis through a generic external LLM API, each discovered consumer is analyzed through Bob’s native parallel agent orchestration. Bob reads the contract delta and the consumer’s actual surrounding source, reasons about whether the call site’s behavior changes, and returns a structured verdict. This is deliberate: the core judgment calls—“does this test still hold?” or “is this guard now dead code?”—are exactly the kinds of tasks suited to Bob’s agentic reasoning. Using Bob directly also avoids rebuilding a weaker orchestration layer from scratch.

We stress-tested this by seeding a second, independent breaking change in a different endpoint of the same proxy layer and having Bob analyze it with no prior ground truth. It correctly identified two previously unseen UI consumers, generalized the untested-frontend pattern from the first bug, and correctly determined that one call site was unaffected because its error handling did not depend on the changed response shape. That distinction required reading the actual code rather than pattern matching.

Throughout development, we verified Bob’s output against the real codebase at every stage rather than accepting summaries at face value. This caught an intermediate case where a script had silently fallen back to a stub instead of invoking Bob. We corrected it so that Bob’s own agent reasoning—not an external API call—is what actually powers the tool’s verdicts.
